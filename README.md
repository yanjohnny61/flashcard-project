# Flashcard Web Application

A lightweight study tool built to practice JavaScript fundamentals, HTML/CSS layout design, and `localStorage` persistence.

## Preview
<img width="419" height="566" alt="image" src="https://github.com/user-attachments/assets/ca583640-2c28-4d11-aeb7-7e7907a9893e" />

## Features
- Card Creation and Deletion
- Arrow key + keyboard navigation to flip and switch cards
- Mastery tracker ("Know / Don't Know")
- Shuffle functionality
- Persistent data with `localStorage`

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla ES6)

## How to Run
No installation or dependencies required! 

1. Clone or download this repository.
2. Open `flashcards.html` directly in any web browser.
